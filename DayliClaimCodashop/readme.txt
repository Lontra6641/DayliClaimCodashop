Código con fines educativos sobre automatización

Este código tem intuito de mostrar como a automação de paginas pode ser usadas de forma simples para tarefas simples, vale ressaltar que é apenas um exemplo de como as funções funcionam e como podem ser colocadas em pratica 

This code is intended to demonstrate how page automation can be used in a straightforward way for simple tasks; it is worth noting that this is merely an example of how the functions work and how they can be put into practice.

Este código tiene como objetivo mostrar cómo la automatización de páginas puede utilizarse de manera sencilla para tareas simples; cabe destacar que es solo un ejemplo de cómo funcionan las funciones y cómo pueden ponerse en práctica.



Como usar (utilizar o Chrome):
Atualize o Chromedriver para a versão mais recente;
Instrução 1: vá na codashop, insira seu uid, confirme, copie e cole a URL;
Executar o .bat. 

How to use (using Chrome):
Update Chromedriver to the latest version;
instruction 1: Go to CodaShop, enter your UID, confirm, copy and paste the URL;
Inside the .bat file, change "presenteDiario" to "DayliGift"
Run the .bat file.
